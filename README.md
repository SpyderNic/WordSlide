# Word Slide

A themed word puzzle for the web. The design is in [docs](docs), and the agreed behaviour is in [features](features).

To run it, from a new terminal in this folder:

```
npm install
npm run dev
```

Then open http://localhost:5173.

- `npm run build` builds the game into `dist`.
- `npm test` runs all the tests. The reports are in `reports`.
